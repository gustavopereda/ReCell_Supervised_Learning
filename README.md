# # ReCell – Used Phone Price Prediction 

## Overview
Built a regression model to predict the price of used smartphones and tablets based on technical specifications and condition.

## Key Metrics
- R²: 0.83
- MAPE (Test): 4.3% — strong predictive accuracy

## Tools Used
- Python (Scikit-learn, Pandas, Matplotlib)
- Linear Regression
- Jupyter Notebook

## Deliverables
- Feature engineering and selection
- Regression modeling and evaluation
- Business insights for device resale platforms

## Recommendation
Use model predictions to automate pricing tools for used electronics platforms and guide inventory purchases.
